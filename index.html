telltale
AOSP dumps, made legible

Drop an AOSP dump here

Reads dumpsys window, SurfaceFlinger, package, user, input, car_service and binder_calls_stats, ANR traces, logcat, and a whole adb bugreport zip as it came off the device. The file never leaves your browser.

No dump to hand? Open a .

How to take one adb shell dumpsys window windows > windows.txt adb shell dumpsys SurfaceFlinger > sf.txt adb shell dumpsys package > packages.txt adb shell dumpsys user > users.txt adb shell dumpsys input > input.txt adb shell dumpsys car_service > car.txt adb logcat -d > logcat.txt adb pull /data/anr/traces.txt # or all of it at once — drop the zip in as it comes adb bugreport bugreports/ # binder_calls_stats records nothing while charging, and samples by default adb shell dumpsys battery unplug adb shell dumpsys binder_calls_stats --enable --no-sampling --enable-detailed-tracking adb shell dumpsys binder_calls_stats --reset # then reproduce, then: adb shell dumpsys binder_calls_stats > binder.txt

A bugreport works too — drop in the zip adb bugreport wrote, or a flat bugreport.txt. Telltale opens the archive and puts every section it knows in a tab of its own. Add ?url= to this page's address to open a dump straight from a link.
